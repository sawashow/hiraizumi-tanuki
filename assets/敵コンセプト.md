# 敵コンセプト

ザコ敵を増やすための、方針と案、絵の指示文。面ごとの全体像は [ステージコンセプト.md](ステージコンセプト.md)、絵の基準は [ドット絵基準.md](ドット絵基準.md)。
ここに書いたものは**案**。作る前に、遊んで足りないと分かった敵から選ぶ。

## 方針

- いまのザコは3種。落ち武者・狐火・烏。1面と2面は、これで回っている。
- 増やすのは、**3面（高館）と4面（金色堂）の分から**。1面の「敵の多さ」と、2面の「池を渡る」は、いまの3種で足りている。2面に足すのは、池の遊びを強める1種だけにする。
- 敵を足す理由は、数を増やすためではなく、**面ごとに「何を求められるか」を変えるため**（[面ごとの差別化の軸](ステージコンセプト.md)）。
- 1つの敵には、1つの新しいルールだけを持たせる。
- **敵の攻撃と動きは、見て分かること。** 分からない攻撃に当たるのは、遊ぶ人のストレスになる。難しさは、見えにくさではなく、配置と組み合わせで作る。
  - 攻撃の前に、予告を、絵と時間で見せる（構える・光る・羽ばたく・地面の目印）。予告なしで当たる攻撃は、作らない。
  - 飛び道具は、どの面の背景の上でも見えること（明るい縁取り。短い辺は6ドット以上）。上から落ちる物は、落ちる場所と筋道を、先に見せる。
  - 見た目を、当たり判定より小さくしない（見えていない所で、当たらないように）。
  - 新しい敵・飛び道具は、4つの面の背景の上に並べた静止画で、見えるかを確かめてから入れる（[画像づくりの手引き](画像づくりの手引き（Antigravity向け）.md) の「小さい敵と、飛び道具の見やすさ」）。

## いまの3種（見本）

| 敵 | 役割 | 体力 | 予告 | 対処 |
|---|---|---|---|---|
| 落ち武者 | 地上の歩兵。近づくと止まって構え、光波を出す | 3 | 構える（止まる） | 光波をよけ（低い・高い）、斬る |
| 狐火 | 空中を上下に揺れながら近づく。低め・高めの2通り | 1 | なし（見えている） | しゃがむ・ジャンプ・手裏剣 |
| 烏 | 空で待ち、近づくと羽ばたき、その位置へ急降下 | 1 | 羽ばたく（30フレーム） | 降りてくる前に、位置をずらす |

共通の型は「**予告 → 攻撃 → 隙**」。予告が見えて、よける方法が1つはあり、隙に反撃できる。新しい敵も、この型に合わせる。

## 作る手順

1. 絵を生成する（下の指示文）。Gemini で作り、白背景のシートを、`assets/concept/source/enemy_◯◯.jpg` に置く。
2. `tools/make_enemy.py` で、コマに変換する（落ち武者などの例が、ファイルの冒頭にある）。
3. `config.py` の `ENEMY_FRAMES`（コマ数）、`ENEMY_ART`（枠の大きさ・基準位置）、数値を追加する。
4. `sprites.py` に、敵のクラスを追加する（`Enemy` を継承。落ち武者の構え、烏の予告が見本）。
5. `stage.py` の `SPAWNS` に置く。
6. `tools/smoke_test.py` に、動きの確認を足す。
7. 通しで遊ぶ。

## 絵の指示文

### 共通（どの敵にも、先頭に付ける）

```
添付した画像は、すでにゲームに入っている敵のシート(烏)です。
これと同じ絵柄・同じ形式で、新しい敵のスプライトシートを描いてください。

【形式】
- 背景は、真っ白(白い無地)。影・地面の線・背景の模様は入れない。
- 動きごとに、横一列に並べる。各行の左上に、動きの名前を日本語で書く。
- 全コマ、同じ大きさ・同じ縮尺。コマとコマの間は、広めに空ける。
- すべて、右向き(画面の右へ向かって動く向き)。
- 足元(または体の下端)は、同じ高さにそろえる。

【絵柄】
- ドット絵。1ドットが、はっきり見える粗さ(滑らかなぼかし・細かい描き込みはしない)。
- 黒に近い、暗い色の輪郭。色数は少なく。
- 夜の平泉の怪異。怖いが、重すぎない。デフォルメして、親しみのある顔にしてもよい。
- 暗い背景(夜)でも埋もれないように、体の縁を、明るい色で少しだけ縁取る。
```

### 弓兵（3面 高館）

```
【敵】弓兵(ゆみへい)。平泉の合戦で散った、足軽の亡霊。

【見た目】
- 古い軽い鎧(胴丸)に、傷んだ陣笠。顔は影になって、目だけが赤く光る。
- 大きさは、落ち武者と同じくらい(立った高さ 約40ドット)。
- 長弓を持っている。矢筒を背負っている。体は、少し半透明の青みを帯びた、灰色。

【動き(行ごとに)】
1. 立ち(2コマ): 弓を持って、わずかに揺れて待つ。
2. 弓を引く(3コマ): 矢をつがえて、弓を引き絞る。最後のコマで、矢先が白く光る。
3. 放つ(2コマ): 矢を放った瞬間(弦が戻る)と、構えを解く。
4. やられ(3コマ): のけぞる → 倒れる → 青い光の粒になって消える。

【別に】矢(横向きに飛ぶ1コマ)と、刀で消されたときの矢の破片(2コマ)も、下に描いてください。
```

### ミイラ（1面 毛越寺・4面 金色堂）

2026-10-12 に入れた、いちばん弱い敵。最初に出会う敵が落ち武者（構えて、光波を撃つ。体力3）だと、強すぎた。
ゆっくり歩いてくるだけで、攻撃はしない。触れるとダメージ。体力1（刀でも手裏剣でも、1発）。穴や段差の手前で、折り返す。
金色堂には、藤原四代のミイラが納められているので、平泉らしい敵でもある。
絵は、2026-10-12 にできた（元絵 `assets/concept/source/enemy_miira.jpg`）。`python tools/make_miira.py 元絵 出力フォルダ` で、コマにする。
元絵は、明るい布に、暗い巻き目が細かく入っていて、そのまま縮めると、暗くつぶれて、青い目も消えた。縮める前に、布を明るくし、目を太らせている。

- ファイル名: `enemy_miira.jpg`
- 見本に添付: `enemy_karasu.jpg`（形式の見本）、`enemy_ochimusha.jpg`（大きさの見本）
- 大きさ: 立った高さ 約40ドット（落ち武者と同じ）

```
【敵】ミイラ(亡者)。金色堂に眠っていた、名もない者のなきがらが、起き上がったもの。

【見た目】
- 全身に、古びた麻の布(生成り色・うすい黄土色)を巻いている。布は、ところどころ、ほどけて垂れている。
- 武器は、持たない。鎧も、着ない。両腕を、前へだらりと伸ばして、前かがみで歩く。
- 顔は、布のすき間から、目だけが、うす青く光る。怖いが、少し間の抜けた、のろまな感じ。
- 大きさは、落ち武者と同じくらい(立った高さ 約40ドット)。落ち武者より、細い。
- 暗い背景でも見えるように、布の色は、明るく。体の縁を、うすい金色で、少しだけ縁取る。

【動き(行ごとに)】
1. 歩く(4コマ): 足を引きずって、ゆっくり歩く。腕は、前へ伸ばしたまま、少し揺れる。垂れた布が、うしろへなびく。
2. やられ(3コマ): のけぞる → 布がほどけて、崩れる → 布のきれと、金色の光の粒になって、消える。
```

### 天狗（3面 高館）

2026-10-14 に入れた。地面を、ぴょんぴょん跳んで近づく（かがむ → 跳ぶ → 着地の隙 のくり返し）。触れるとダメージ。体力2。
穴や段差の手前では跳ばない（`sprites.py` の `Tengu`、`config.py` の `TENGU`）。高館に3体（谷・関の手前・頂上）。
絵は、2026-10-14 にできた（元絵 `assets/concept/source/enemy_tengu.jpg`）。`python tools/make_tengu.py 元絵 出力フォルダ` で、コマにする（枠 43×46）。
元絵の装束は、暗い藍色で、そのまま縮めると、黒くつぶれた。縮める前に、藍色を、明るく・青く持ち上げている。消える羽根（やられの最後のコマ）は、黒くて細いので、範囲を指定して、そのまま切り出している。白い房（胸の丸）は、小さくて、つぶれ気味。
コマの使い方: walk の 0 = 待つ / 1 = 空中 / 2 = かがむ（予告）/ 3 = 着地（いまは使わない。予備）。名前は walk だが、実際は、この4つの姿。

- ファイル名: `enemy_tengu.jpg`
- 見本に添付: `enemy_ochimusha.jpg`（大きさの見本）、`enemy_miira.jpg`（形式の見本）
- 大きさ: 立った高さ 約40ドット（落ち武者と同じ）。ゲーム用の枠は 62×51（落ち武者と同じ）。違えば `ENEMY_ART` の数字を直す

```
【敵】天狗(山の妖)。高館の山にすむ、すばしこい妖。高く跳ねて、人に跳びかかる。

【見た目】
- 山伏(やまぶし)の姿。濃い藍色の装束に、頭に小さな黒い頭巾(ときん)。胸に、白い丸い房(梵天)。
- 顔は赤く、鼻が高く長い。目は鋭く、金色に光る。口は、への字。
- 背中に、小さな黒い翼を、たたんでいる(跳ぶときだけ、少し開く)。
- 手に、小さな羽団扇(はうちわ)を持つ。武器にはしない(飾り)。
- 大きさは、落ち武者と同じくらい(立った高さ 約40ドット)。身軽な感じで、細め。
- 暗い背景でも見えるように、顔の赤と、装束の縁を、明るめに。

【動き(行ごとに)】
1. 動き(4コマ、右向き): ①待つ(軽く膝を曲げて、体を揺らす) ②空中(跳び上がった瞬間。翼が開き、脚は曲がる) ③かがむ(跳ぶ直前。深く沈み、力をためる) ④着地(膝を曲げて、衝撃を受ける)
2. やられ(3コマ): のけぞる → 羽根が散って、崩れる → 黒い羽根と、金色の光の粒になって、消える。
```

### 立ち往生（3面 高館）

> **2026-10-12 に、役割を変えた**: 立ち往生（弁慶）は、道ばたの敵をやめて、**高館の中ボス**にした。
> 「倒せない」「正面は弾く・うしろから斬る」は、どちらも、見て分からなかった（悪魔城にも、同じ型の敵はいない）。
> いまは、中間地点の手前の「弁慶の間」に立っていて、動かない。どこから斬っても効く。離れていると薙ぎ（光波。低い = 跳ぶ / 高い = しゃがむ）、
> 近づくと突き（速いが、短い。下がる）。攻撃のあとに隙。倒すと、光になって消えて、先へ進める（`sprites.py` の `Benkei`、`config.py` の `BENKEI`、`stage.py` の `GATES3`）。
> 以下の「立ち往生」の記述は、それまでの案。
>
> **同じ日のうちに、中ボスも、面から外した。** 役割を3回変えても（倒せない壁 → 正面は弾く → 中ボス）、はっきりしなかった。
> 原因は、「立ったまま動かない絵が1枚ある」ところから始めて、絵に合う役割を、あとから探したこと。中ボスの中身も、借り物だった
> （攻撃は、ほかのボスと同じ光波。絵が2コマしか無く、予告は矢印。名前も、登場の演出も、話の中での立場も無い。中ボスがいるのは高館だけ）。
> 仕組みと絵は残してある（`stage.py` の高館に `gates=((2820, "benkei"),)` を足せば、戻る）。
> **戻すなら、先に役割を1つに決めて、絵を一式そろえてから。** 案: 義経堂の門番として、高館のボスにする（薙刀そのもので戦う。光波は使わない）。


```
【敵】立ち往生(たちおうじょう)。弁慶の、立ったまま動かなくなった姿。

【見た目】
- 大男。落ち武者の1.5倍くらいの大きさ(立った高さ 約60ドット)。
- 薙刀を杖のように立てて、仁王立ち。全身に、矢が何本も刺さっている。
- 目は閉じている。体は、暗い灰色と、くすんだ赤。ぼろぼろの僧衣と鎧。
- 動かないが、わずかに、息をするように揺れている。

【動き(行ごとに)】
1. 立つ(2コマ): ほとんど動かない。わずかな揺れ(1ドットだけ上下)。
2. 刀を弾く(2コマ): 斬られたとき。白く光って、のけぞらずに、ふんばる。
(倒れる動きは、描かない。倒せない敵です。)
```

### 唐傘小僧（2面 毛越寺・3面 高館）

```
【敵】唐傘小僧(からかさこぞう)。古い唐傘に、目と舌と、一本足が生えた妖怪。

【見た目】
- 開いた、破れかけの唐傘が体。傘の中ほどに、大きな目玉が1つ。長い舌が、だらりと垂れる。
- 足は、下駄をはいた一本だけ。小さな手が、傘の柄のわきから出ている。
- 大きさは、小さめ(高さ 約28ドット)。傘は、くすんだ朱か、古びた紙の色。
- 怖さより、とぼけた愛嬌を出す(ゲームの息抜き役)。

【動き(行ごとに)】
1. 着地(2コマ): 下駄で着地して、傘が少しつぶれる → ためる。
2. 跳ぶ(3コマ): 傘が開いて、跳び上がる → 頂点(傘がふくらむ) → 落ちていく(傘がすぼむ)。
3. やられ(3コマ): 傘がひっくり返って、骨が散る → 目玉がきょとんとして、ぽんと消える。
```

### 金の蝶（4面 金色堂）

【敵】金(きん)の蝶。金色堂の螺鈿(らでん)の光から生まれた、光の蝶。

【見た目】
- 小さい(羽を広げて約16ドット)。羽は、金色と、螺鈿の青緑がまざった色。
- 体は、細くて黒に近い。鱗粉が、きらきら光る。

【動き(行ごとに)】
1. 羽ばたき(4コマ): 羽を閉じる → 半開き → 全開 → 半開き(ループ)。
2. やられ(3コマ): 羽が光の粒になって、散る。最後は、粒だけが残る。

## 唐傘小僧について（通り過ぎる敵）

いまのザコは、どれも主人公を狙う（近づく・構える・急降下）。唐傘小僧は、**主人公に構わず、跳ねながら横切るだけ**の敵。

- 面の「リズム」を作る役。戦いではなく、「いつ通り抜けるか」を考えさせる。
- ジャンプが中心の2面と相性がよい。池のそばで跳ねる唐傘を、よけながら、飛び石を渡る。
- 3面では、弓兵の矢と重なると、考えることが増える。数を絞って、少しだけ出す。
- 当たればダメージ。ただし、跳ぶ周期が一定なので、読めばよけられる。
- 愛嬌のある絵にして、重い面の中の、息抜きにする。

## 決めたこと（おすすめで決定。遊んで合わなければ変える）

| 項目 | 決定 | 理由 |
|---|---|---|
| 唐傘小僧の出方 | ほかの敵と同じく、面のデータ（`SPAWNS`）に位置を書く。主人公が近づく（約320）と、**右の画面の外から、左へ**跳ねてくる | 追加の仕組みがいらない。「通りがかった」感じも出る |
| 唐傘小僧の向き | 左向きに進み、画面の左へ出たら消える。折り返さない | 「通り過ぎるだけ」の約束を守る |
| 弓兵の矢を、刀で消したとき | 手裏剣で敵を倒したときと同じ、小さな点が入る | 「撃たれる面」で、斬って防ぐ動きに、手応えを付ける |
| 立ち往生の扱い | **敵として扱う**（`Enemy` の仲間）。倒せない・ダメージなし。触れると、手前へ押し戻す。刀・手裏剣は、白く光って弾かれる（弾く音も付ける）。乗れない。飛び越えて進む | 地形にすると、ただの背景に見えて、避ける相手と分からない。敵として描き、弾かれる反応が出れば、「触れてはいけないもの」と伝わる |
| 鯉の怨霊の位置 | 池（地面の穴）の**真ん中**から跳ぶ。位置は、地形の穴から自動で求める | 池の位置を、別に書かなくてよい |

## まだ決まっていないこと

- 金の蝶の軌道を、光の足場と、どうつなげるか（4面の仕掛けが決まってから）。蝶は、最後に作る。
