# ドット絵基準

ゲーム中の絵は、この基準に合わせて作る・変換する。

## 方針

- 絵は Gemini で作り、`tools/` のスクリプトで基準に合わせて変換する（元絵は `assets/concept/source/` に置く。リポジトリには含めない）
- 画面は 480×270（16:9）。表示は2倍の 960×540
- 粒度は、画面の1ドット＝論理ピクセル1つにそろえる。元絵の1ドットの大きさが絵ごとに違うので、変換のとき縮尺をそろえる
- 小さな主人公では顔の判別は難しい。タヌキと分かる決め手は「しっぽの縞と全体のシルエット」。顔の判別は、タイトル画面などの顔アップで補う予定

## 基準

| 項目 | 基準 |
|---|---|
| 画面 | 480×270 |
| 主人公の絵の枠 | 64×48（体は高さ約 40） |
| 主人公の当たり判定 | 体だけ（16×36）。しっぽと刀は見た目だけ |
| 足元・頭の位置 | 全コマで、足元を枠の下端、頭の位置を `HEAD_X`（35）にそろえる |
| 色（キャラ） | 固定8色のパレットに寄せ、輪郭は黒。元絵が暗いときは明るさを補正（1.3倍） |
| 手裏剣・命中エフェクト | 24×24 の枠 |
| 地面タイル | 32 幅（上端のタイルは 32×17、他は 32×32）。夕暮れの色味に寄せる |
| 背景 | 遠景 870×270、中景 1446×270（透過）。面の長さ 2400 に対して、カメラの動きに比例してスクロール |

## 変換ツール（`tools/`）

| ファイル | 内容 |
|---|---|
| `slice_sheet.py` | スプライトシート（白背景）をコマに切り出し、枠にそろえて変換する |
| `make_shuriken.py` | 手裏剣（回転と命中の破片）を小さな枠に変換する |
| `make_sky.py` | 遠景を画面の高さに合わせて変換する（月の大きさと色を調整） |
| `make_mid.py` | 中景を透過PNGに変換する（灯籠の灯りを残す） |
| `make_tiles.py` | 地面タイルを切り出して変換する（色味の調整つき） |
| `make_title_logo.py` | スタート画面の題名を、昔のゲームのロゴ風の絵に書き出す |
| `make_boss_name.py` | ボスが出てくる場面の、二つ名と名前（ふりがな付き）の絵を書き出す |
| `make_sfx.py` | 効果音（雷鳴・刀・中間地点）を、計算で作って書き出す |
| `make_story_text.py` | 始まりの語り（`assets/story_intro.txt`）を、縦に長い1枚の絵に書き出す |
| `make_gif.py` | 動きごとの確認用GIFを作る |
| `build_web.py` | ブラウザ版（pygbag）用に、必要なファイルだけを `web/` にコピーする |
| `smoke_test.py` | 画面なしで操作を再生して、動きを確かめる |
