# ドット絵基準

ゲーム中の絵は、この基準に合わせて作る・変換する。

## 方針

- 絵は生成AI（Gemini、一部 ChatGPT）で作り、`tools/` のスクリプトで基準に合わせて変換する。元絵は `assets/concept/source/` に置く（リポジトリには含めない。対応は `assets/concept/README.md`）
- 画面は 480×270（16:9）。表示は2倍の 960×540
- 粒度は、画面の1ドット＝論理ピクセル1つにそろえる。元絵の1ドットの大きさが絵ごとに違うので、変換のとき縮尺をそろえる
- 小さな主人公では顔の判別は難しい。タヌキと分かる決め手は「しっぽの縞と全体のシルエット」。顔の判別は、タイトル画面などの顔アップで補う
- 面ごとに色味は変えてよいが、**黒い輪郭と、ドットの粗さはそろえる**。AIの絵は細かすぎるので、背景は2〜3ドット角に落とし、色数を絞る
- ChatGPT と Gemini の絵を混ぜるときは、変換で粗さと色数をそろえてから使う（そのまま使うと、絵柄の差が出る）

## 基準

| 項目 | 基準 |
|---|---|
| 画面 | 480×270 |
| 主人公の絵の枠 | 64×48（体は高さ約 40）。37コマ（立ち・歩き・ジャンプ・攻撃・手裏剣・被弾・やられ・しゃがみなど） |
| 主人公の当たり判定 | 体だけ（16×36）。しっぽと刀は見た目だけ |
| 足元・頭の位置 | 全コマで、足元を枠の下端、頭の位置を `HEAD_X`（35）にそろえる |
| 色（キャラ） | 固定8色のパレットに寄せ、輪郭は黒。元絵が暗いときは明るさを補正 |
| 敵 | 落ち武者 62×51、狐火 16×18、烏 42×25。ボスは仮の絵（落ち武者の2倍）。暗い敵には、明るい縁取り（`--rim`） |
| 手裏剣・命中エフェクト | 24×24 の枠 |
| 光波 | 敵（白〜薄い紫）と主人公（水色）。高さ約 28〜32。黒い輪郭なし |
| アイテム | 団子・おにぎり・金の葉。高さ約 15〜23。拾う範囲は 16×16 |
| 中間地点（鳥居） | 約 43×46。通る前（くすんだ赤）と通った後（朱色、きらめき） |
| 文字 | ドット風フォント DotGothic16（OFL）で書き出した絵。ゲームにフォントは入れない |

## 面ごとの絵（`assets/images/`。2面以降は `stageN/`）

| 項目 | 1面（月見坂） | 2面（毛越寺） |
|---|---|---|
| 遠景 | 870×270。夕焼けと満月 | 810×270。夜明け前の朝霧。3ドット角、12色 |
| 中景 | 1446×270（透過）。杉並木と灯籠 | 1510×270（透過）。常行堂・中島・反橋・松。2ドット角、24色 |
| 地面タイル | 32 幅（上端 32×17、他 32×32）。石畳・苔・落ち葉 | 32 幅（上端 32×25、他 32×32）。苔の石組み・玉砂利。2ドット角、10色。上端に黒い縁取り |
| 足場 | 地面の上端のタイル | 礎石3種（約 45×23）。足場の幅に合わせて、横に伸ばす |
| 池の水面 | 暗い四角（穴） | 絵ができたら `water_top_0/1.png`・`water_fill.png`（無ければ暗い四角） |
| 面の名前 | `stage_title_N.png`（縦書き。右に「第N面」、中央に地名、左に副題） | 同左 |
| 石碑 | `stele_N.png`（地名を彫った石碑） | 同左 |

面ごとの絵が無いときは、1面の絵で代わりにする（`StageDef` と `Assets.load_stage`）。

## 変換ツール（`tools/`）

| ファイル | 内容 |
|---|---|
| `pixelize.py` | 共通の部品（パレット、輪郭、縮小） |
| `slice_sheet.py` | 主人公のスプライトシート（白背景）をコマに切り出し、枠にそろえて変換する |
| `make_enemy.py` | 敵のシートを、コマに変換する（地面の線・文字の除去、縁取り） |
| `make_shuriken.py` | 手裏剣（回転と命中の破片）を小さな枠に変換する |
| `make_wave.py` | 光波の絵を変換する（`--violet` で白〜薄い紫） |
| `make_items.py` | アイテム・鳥居・石碑・礎石など、横一列の物を切り出して変換する（`--clear-white` で閉じた白も消す） |
| `make_sky.py` | 1面の遠景を、画面の高さに合わせて変換する（月の大きさと色を調整） |
| `make_mid.py` | 中景を透過PNGに変換する（灯籠の灯りを残す） |
| `make_tiles.py` | 地面タイルを切り出して変換する（色味の調整、`--square` で横長を正方形に） |
| `make_text_image.py` | 短い日本語を、ドット風フォントで透過PNGに書き出す |
| `make_stage_text.py` | 面の名前（縦書き）と、地名を彫った石碑を書き出す |
| `make_title_logo.py` | スタート画面の題名を、昔のゲームのロゴ風の絵に書き出す |
| `make_boss_name.py` | ボスの二つ名と名前（ふりがな付き）の絵を書き出す |
| `make_talk_text.py` | ボスを倒したあとの寸劇の、せりふの絵を書き出す |
| `make_story_text.py` | 始まりの語り（`assets/story_intro.txt`）を、縦に長い1枚の絵に書き出す |
| `make_sfx.py` | 効果音（雷鳴・刀・中間地点・せりふ）を、計算で作って書き出す |
| `make_gif.py` | 動きごとの確認用GIFを作る |
| `build_web.py` | ブラウザ版（pygbag）用に、必要なファイルだけを `web/` にコピーする |
| `smoke_test.py` | 画面なしで操作を再生して、動きを確かめる（約300項目） |
