# 必要な絵の一覧（絵を作る人・AI向け）

「平泉タヌキ侍」（2D横スクロールアクション。Python / pygame）に、これから足したい絵をまとめたもの。
ゲームの組み込み（コード・変換・配置）は、こちらでやる。**絵を作って、決まった名前で、決まった場所に置いてもらえれば足りる。**

## 先に読むもの

- 絵の基準: [ドット絵基準.md](ドット絵基準.md)（画面 480×270、粗さ、色数、輪郭）
- 各面の雰囲気: [ステージコンセプト.md](ステージコンセプト.md)
- 敵の案と、絵の指示文: [敵コンセプト.md](敵コンセプト.md)（敵の絵は、ここの「絵の指示文」を、そのまま使う）
- 見本の絵（絵柄をそろえるために、添付して使う）は、すべて `assets/concept/source/` にある

## 渡し方

1. 絵は、`assets/concept/source/` に、下の表の**ファイル名**で置く（jpg か png。1枚に1つの用途）。
2. 置いたら、「◯◯を置いた」と伝える。変換・組み込みは、こちらでやる（変換ツールは `tools/` にある）。
3. 1つの用途につき、気に入ったものが出るまで、何枚作り直してもよい。**選んだ1枚だけ**を、決まった名前で置く。

## 共通の絵柄（どの絵にも、先頭に付ける）

```
ドット絵（ピクセルアート）。SFC風（スーパーファミコンのような粗さ）。
1ドットが、はっきり見える粗さにする（なめらかなぼかしや、細かい描き込みはしない）。
黒に近い、暗い色の輪郭。色数は少なく。
文字・ロゴ・枠・サインは入れない（指示した行の見出しだけ、日本語で書いてよい）。
舞台は、岩手県の平泉（中尊寺・毛越寺・高館・金色堂）。藤原四代の亡霊が出る、夜の怪異の物語。
怖いが、重すぎない。親しみのある、少しとぼけた味も出す。
```

敵・ボスの絵は、さらに次を守る（変換ツールが前提にしている）:

- 背景は真っ白（無地）。影・地面の線・背景の模様は入れない。
- 動きごとに、横一列に並べる。各行の左上に、動きの名前を日本語で書く（変換ツールが、文字を消す）。
- 全コマ、同じ大きさ・同じ縮尺。コマとコマの間は、広めに空ける。
- すべて右向き。足元（または体の下端）の高さを、そろえる。
- 暗い背景（夜）に埋もれないよう、体の縁を、明るい色で少しだけ縁取る。

背景の絵は、白背景の「中景」と、全面の「遠景」の2種類がある（下の各項に書く）。

## 優先度: 高

### 1. 弓兵（敵・3面 高館）

- ファイル名: `enemy_yumihei.jpg`
- 動き（行ごと）: 立ち 2コマ / 弓を引く 3コマ / 放つ 2コマ / やられ 3コマ。別に、矢（横向き1コマ）と、刀で消された矢の破片2コマ
- 指示文: [敵コンセプト.md](敵コンセプト.md) の「共通」と「弓兵（3面 高館）」を、続けて使う
- 見本に添付: `enemy_karasu.jpg`（形式の見本）、`enemy_ochimusha.jpg`（大きさの見本）
- 大きさ: 立った高さ 約40ドット（落ち武者と同じくらい）

### 2. 立ち往生（敵・3面 高館）

- ファイル名: `enemy_tachiojo.jpg`
- 動き（行ごと）: 立つ 2コマ（ほとんど動かない） / 刀を弾く 2コマ（白く光って、ふんばる）。倒れる絵は、要らない（倒せない敵）
- 指示文: [敵コンセプト.md](敵コンセプト.md) の「共通」と「立ち往生（3面 高館）」
- 見本に添付: `enemy_ochimusha.jpg`
- 大きさ: 立った高さ 約60ドット（落ち武者の1.5倍）。弁慶。薙刀を杖のように立てて、仁王立ち。全身に矢

### 3. 金色堂の背景（4面。遠景を、あと2〜3枚）

4面は、いちばん長い面（長さ9000）。いまは、堂の中の背景が1枚だけなので、区間ごとに場面を変えたい。
いまの絵（`stage4_bg.jpg`）と同じ絵柄・同じ配色（黒・金・朱・螺鈿の青緑）で、**別の場所**を描く。

| ファイル名 | 場面 | 使う区間 |
|---|---|---|
| `stage4_bg_corridor.jpg` | 堂の外の回廊と階段。夜明け前の、青みがかった空と、朱の欄干。遠くに、金色堂の覆い堂 | 入口の間・回廊 |
| `stage4_bg_pillars.jpg` | 高い金の柱が何本も立ち並ぶ、広い堂の内部。天井近くに、螺鈿の光（青緑）が散る | 柱の間 |
| `stage4_bg_inner.jpg` | 奥の間。須弥壇（金の台）と、光の柱。いちばん明るく、荘厳。ボスの前の場所 | 奥の廊下・清衡の間 |

- 大きさ: 1376×768（16:9）。人物・敵は入れない。地面（床）は、画面の下の、暗い帯にする（ゲーム側の床タイルを、上に重ねる）
- 見本に添付: `stage4_bg.jpg`

### 4. 月見坂の後半の中景（3面）

月見坂の長さを、4080から7500に延ばした。後半は、頂上に近づく。前半と同じ景色が続くので、後半用の景色を足したい。

- ファイル名: `stage1_mid_late.jpg`（白背景の「中景」。透過に変換するので、背景は真っ白）
- 内容: 夕焼けから夜の、杉並木の、高い所。幹の太い杉、石灯籠（灯りは橙）、石段の一部。**遠くに、金色堂の屋根が、小さく見える**（頂上が近い）。右端は、杉の幹で終わる
- 大きさ: 1376×768。杉の足元は、画面の下から1/4あたりにそろえる（ゲーム側で、地面の上に重ねる）
- 見本に添付: `assets/images/bg_mid.png`（いまの月見坂の中景。絵柄・配色をそろえる）、`stage3_mid.jpg`（白背景の形式の見本）

## 優先度: 低

### 8. 月見坂専用の地面タイルと足場

- ファイル名: `stage1_tiles.jpg`
- 形式: `stage3_tiles.jpg` と同じ（白背景。3行3列。上から、草でなく**石畳の上端**、石垣、苔の石段、落ち葉の混じる土 など。足場の石2種）
- 色味: 夕焼けに合う、少し暖かい灰色と、茶。苔の緑は、くすませる
- 見本に添付: `stage3_tiles.jpg`、`assets/images/tile_00.png`〜（いまの月見坂のタイル）

### 9. 影のボス（任意）

いまは、本家のボスの絵に、暗い青を重ねて、影にしている。専用の絵が欲しければ、本家の絵（泰衡・基衡・秀衡）を見本に、
「輪郭がゆらぎ、足元が消えかけた、青黒い影」の版を、同じ動きで作る。優先度は低い（色の重ねで、十分に影に見える）。

### 10. 夏草の亡者・朧（敵・案）

- ファイル名: `enemy_natsukusa.jpg` / `enemy_oboro.jpg`
- 指示文: [敵コンセプト.md](敵コンセプト.md) の案の表を見て、共通の指示文に、動きを書き足して作る
- 面が単調に感じたときの予備。まだ急がない

## 作ってもらったあと、こちらでやること（参考）

| 絵 | 変換 | 組み込み |
|---|---|---|
| 敵（1〜2、5〜7、10） | `tools/make_enemy.py` | `config.py` の `ENEMY_FRAMES`・`ENEMY_ART`・数値、`sprites.py` に敵のクラス、`stage.py` の `SPAWNS` に配置 |
| 背景（3、4） | `tools/make_stage4.py` と同じ方式（遠景: 縮小。中景: 白を透過） | 面ごとの背景を、区間で切り替える仕組み（いまは、1面に1枚） |
| タイル（8） | `tools/make_stage3.py` と同じ方式 | `StageDef` のタイルの置き場 |

絵ができたら、`tools/difficulty.py` で、敵を足した面の難易度（密度）を測り直して、目標に合わせる。
